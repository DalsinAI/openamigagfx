# OpenKick's ROM screen font, 8 pixels high: topaz.font 8 (8 x 8 cells,
# baseline row 6, one descender row), the name old programs open. The letters
# are DejaVu Sans Mono's (see DEJAVU-LICENCE.txt): drawn at 10 pixels with the
# font's own hinting, one bit deep, then finished by hand, glyph by glyph, in
# this file for OpenGfx (24 October 2026). It replaces the Team's earlier
# two-pixel-stem drawing; nothing in it comes from Commodore's or AROS's topaz.
#
# The design: one-pixel strokes only (no doubled uprights); ink in columns 1-6
# (letters that stand on a centre stroke, such as T, I, Y, V and the digit 1,
# in columns 1-5 with that stroke on column 3); column 7 and column 0 are the
# gap between letters. Capitals, digits and ascenders rows 0-6; small letters
# rows 2-6. A tail (g j p q y) takes row 7 and its bowl stands a row shorter,
# so the tops of the small letters stay on one line. The zero is dotted.
#
# "@ c" starts a glyph (c a character, or 0xNN); "@ default" is the glyph
# for characters outside 32..255 and for 127..159. "@ accent.NAME" are the
# marks and "@ cap.X" the short capitals (rows 2-6) mkfont.py builds the
# accented Latin-1 letters from. Rows: '#' ink, '.' none.
